# FX Signal Lab

USD/JPY の「5分後の方向」を分析する個人用Webアプリです。

画面上部で「データ」と「分析」をそれぞれ切り替えられます。

| データ | 内容 |
|---|---|
| サンプル | 架空のデータ。市場が閉まっていても操作を試せる |
| 実データ | Twelve Data から取得した USD/JPY の1分足 |

| 分析 | 内容 |
|---|---|
| Claude AI | ローソク足と指標を Claude に渡し、5分後の方向・見込み・理由を答えてもらう（1回ごとにAPI料金） |
| デモ指標 | 移動平均・勢い・RSI から機械的に判断（AIは使わない・無料） |

取引・発注・口座連携の機能はありません。

## 起動方法

1. Node.js 20 以上をインストール（`node -v` で確認）
2. プロジェクト直下（`package.json` と同じ場所）に `.env.local` を作り、次の2行を書く

```
FX_DATA_API_KEY=（Twelve Data のAPIキー）
ANTHROPIC_API_KEY=（Claude API のキー）
```

任意で、使うモデルと1日の上限回数も書けます（`.env.example` 参照）。

3. このフォルダでターミナルを開き、次を実行

```bash
npm install      # 初回と、package.json が変わったとき
npm run dev      # 開発用サーバーを起動
```

4. ブラウザで http://localhost:3000 を開き、上部の「実データ」を選ぶ
5. 止めるときはターミナルで `Ctrl + C`

`.env.local` を書き換えたときは、必ずサーバーを再起動してください（Ctrl + C → `npm run dev`）。

| コマンド | 内容 |
|---|---|
| `npm run typecheck` | TypeScript の型チェック |
| `npm run build` | 本番用にビルド |
| `npm run start` | ビルド後の本番モードで起動 |

## 実データモードのしくみ

- ブラウザは自分のサーバー（`/api/candles`）にだけ問い合わせます。APIキーはサーバー側でだけ使い、ブラウザには送りません
- 画面を開いている間だけ1分ごとに自動更新し、裏に回っている間は取得しません
- サーバーは結果を約50秒使い回すので、複数タブを開いても外部APIへの問い合わせは増えません
- 1回の取得は直近150本（約2.5時間分）。形成中の足は除き、確定した足だけを使います
- 無料プランの上限は1分8回・1日800回。この使い方なら1時間あたり約60回です
- 最新の足が10分以上前で止まっているときは「市場が閉まっている」と表示し、分析できないようにします（土日・祝日など）
- 取得に失敗しても、勝手にサンプルデータへ切り替えることはしません。画面に理由を表示します
- 予測から5分後の足が届くと自動で照合し、結果をブラウザに保存します。アプリを閉じていて取得範囲から外れた予測は「取得できず」になります

## Claude 分析のしくみ

- ブラウザは自分のサーバー（`/api/analyze`）にローソク足を送り、サーバーが Claude API を呼びます。APIキーはサーバー側だけで使います
- Claude には直近60本の1分足と、計算済みの指標（移動平均・RSI・直近5分/15分の変化・値幅）を渡します
- 回答は JSON 形式（方向・上昇/下落/保留の見込み・理由）で受け取り、合計100にそろえてから表示します
- 根拠が弱いときは「判断保留」を選ぶよう指示しています。見込みの数値は Claude の主観で、実際の確率ではありません
- 費用の目安：既定の `claude-haiku-5-5` なら1回あたり0.1円未満（入力約2,000トークン）。`CLAUDE_MODEL=claude-sonnet-5-5` にすると約20倍
- 使いすぎ防止：連続実行は5秒あける・1日の上限（既定200回、`CLAUDE_DAILY_LIMIT`）・同じ足の再分析は前回の結果を使い回す（無料）
- Claude が失敗したときは理由を表示します。勝手にデモ指標へ切り替えず、「今回はデモ指標で分析する」ボタンで選べます

## 画面

- **分析（/）**：サンプル／実データの切り替え、ローソク足チャート、「AI分析を実行」、予測結果（スコア・理由）、予測履歴
- **検証（/verify）**：予測と5分後の実績の比較、集計、値動きグラフ（いま選んでいるデータの履歴を表示）。「Claude／デモ指標」で絞り込み、両方の一致率を並べて比べられます

サンプルと実データの履歴は別々に保存され、混ざりません。

## フォルダ構成

```
app/
  layout.tsx            全ページ共通の枠（ヘッダー・注意書き）
  page.tsx              分析画面
  verify/page.tsx       検証画面
  api/candles/route.ts  実データの取得窓口（サーバー側）
  api/analyze/route.ts  Claude 分析の窓口（サーバー側。回数制限・キャッシュ）
components/             画面の部品（チャート、結果パネル、状態表示など）
lib/
  config.ts             通貨ペア・予測期間などの設定
  sampleData.ts         架空のローソク足（サンプルモード）
  server/twelveData.ts  Twelve Data からの取得と変換（サーバー専用）
  useLiveCandles.ts     実データの自動更新
  server/claudeAnalyzer.ts  Claude へのプロンプト・回答の検証（サーバー専用）
  analyzer.ts           デモ指標による分析
  verify.ts             予測と実績の照合
  store.tsx             画面間で共有する状態と履歴
```

## うまく動かないとき

| 表示 | 対処 |
|---|---|
| APIキーが設定されていません | `.env.local` の場所・ファイル名（`.txt` が付いていないか）・書き方を確認し、サーバーを再起動 |
| APIキーが正しくない | Twelve Data のダッシュボードでキーを確認して `.env.local` を修正し、再起動 |
| 無料枠の利用上限 | 数分待ってから「再取得」。1日の上限なら翌日まで待つ |
| 市場が閉まっているようです | 正常です。平日の市場が開いている時間に使ってください |
| Anthropic のAPIキーが設定されていません | `.env.local` に `ANTHROPIC_API_KEY=` の行を足して再起動 |
| クレジット残高が足りません | Claude Console の Billing でクレジットを追加 |
| Claude API が混み合っています | 1分ほど待って再実行 |

## 安全のための約束

- 予測と見込みの数値は分析の参考値で、実際の確率や的中率ではありません。精度は検証画面で確かめます
- 自動発注・証券口座との連携はありません
- APIキーはブラウザ側に置かず、`.env.local` は Git に含めません

# 株スイング（日本株の決算 × トレンド検証）

ヘッダーの「株スイング」から使います。設計の詳細は `docs/STOCK_SWING.md` を参照してください。

## 準備

1. **J-Quants**：jpx-jquants.com でユーザー登録 → ダッシュボードの「APIキー」で発行
2. `.env.local` に追記して、サーバーを再起動

```
JQUANTS_API_KEY=（J-Quants のAPIキー）
JQUANTS_PLAN=free
```

3. （任意）**Supabase** に保存する場合
   - Supabase で新しいプロジェクトを作る
   - SQL Editor に `supabase/migrations/001_stock_swing.sql` を貼り付けて実行
   - Project Settings → API の「Project URL」と「service_role」キーを `.env.local` に書く

```
SUPABASE_URL=https://xxxx.supabase.co
SUPABASE_SERVICE_ROLE_KEY=（service_role キー）
```

   Supabase を設定しない場合は、プロジェクト直下の `.data` フォルダに保存されます（手元で試す用。Vercel では使えません）。

## 使い方

1. **銘柄分析**：4桁コードを入れて「データを取得」→ トレンドと決算の数値を確認 →「Claude で採点」
2. **バックテスト**：① データを取得 → ② 未採点をまとめて採点 → ③ 実行。スコア帯別の成績で「スコアに意味があるか」を確認
3. **検証ログ**：気になる開示を「検証ログに記録」→ 後日「最新の日足で更新」（日々追うにはライトプラン）

## 注意

- 無料プランは1分5回まで。初めての銘柄は1つあたり最大40秒ほどかかります（アプリが自動で間隔をあけます）
- 無料プランのデータは12週間遅れ・約2年分。バックテスト専用と考えてください
- 結果は過去データに基づく参考値です。取引回数が少ないうちは偶然の影響が大きく、将来の成績を保証しません
